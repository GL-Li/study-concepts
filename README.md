## Rust

### rust-axum
Axum is a framework to build REST API server in Rust. A axum server takes in a HTTP request from a client and sends back a HTTP response to client.

**Tutorials**
- `rust/rust-axum/tutorial-rust-axum.html`: basics of axum framework
- `rust/rust-axum/tutorial-http-with-axum.html`: basic of HTTP, explained with axum

**Projects**
- `~/gl-learn/study-projects/deployment/google-cloud-run-axum-rig-agent/`: deploy an axum application to Google Cloud
